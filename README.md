# حسابداری ساده (mali_catalizor)

نرم‌افزار مالی سبک تحت وب (PWA‑friendly) برای ثبت **ورودی** و **خروجی** با تاریخ شمسی، علت، طرف حساب، روش پرداخت و شماره سند.
بدون وابستگی خارجی؛ فقط Node.js ‎22.13+‎ (دیتابیس SQLite داخلی).

## امکانات
- داشبورد: جمع ورودی/خروجی/مانده (با انیمیشن)، نمودار میله‌ای، نمودار دونات هزینه‌ها به تفکیک علت، فیلتر بازه (ماه/۳۰ روز/سال/همه)
- ثبت، ویرایش و حذف تراکنش با انتخابگر تاریخ شمسی
- جستجو و فیلتر (نوع، دسته، بازه تاریخ) + خروجی CSV (باز شدن در اکسل)
- دسته‌بندی (علت ورودی/خروجی) قابل مدیریت
- گزارش فعالیت‌ها (چه کسی چه کاری کرد)

## اجرای محلی
```bash
ADMIN_USER=admin ADMIN_PASS='رمز-قوی' npm start   # http://localhost:3000
```
اگر `ADMIN_PASS` ندهید، رمز تصادفی در لاگ اولین اجرا چاپ می‌شود. داده‌ها در `data/finance.db` ذخیره می‌شوند.

## استقرار (لایو کردن)
1. **سرور ایرانی/VPS (پیشنهادی برای دسترسی پایدار در ایران):** یک VPS اوبونتو بگیرید، Docker نصب کنید:
   ```bash
   docker build -t mali .
   docker run -d --restart=always -p 3000:3000 -v mali-data:/data \
     -e ADMIN_USER=admin -e ADMIN_PASS='رمز-قوی' --name mali mali
   ```
   سپس Caddy/Nginx را جلوی آن بگذارید تا **HTTPS** بدهد (مثلاً Caddy: `finance.example.ir { reverse_proxy localhost:3000 }`).
2. **پلتفرم‌های ابری (Railway / Render / Fly.io):** ریپو را وصل کنید، Dockerfile خودکار شناسایی می‌شود. حتماً یک **Volume دائمی** روی `/data` بگذارید وگرنه با هر دیپلوی داده پاک می‌شود. متغیرهای `ADMIN_USER` و `ADMIN_PASS` را تنظیم کنید.
3. **بکاپ:** فایل `/data/finance.db` را روزانه کپی کنید (cron یا بکاپ خودکار VPS).

## امنیت
رمزها با scrypt هش می‌شوند، کوکی نشست HttpOnly/SameSite است (روی HTTPS خودکار Secure)، ورود ناموفق محدود می‌شود، و همه عملیات ثبت/ویرایش/حذف در لاگ می‌ماند.
